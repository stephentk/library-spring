# Spring Boot REST API Lab

This project is a hands-on Spring Boot REST API lab focused on building and testing a simple backend application using the Spring ecosystem. The lab demonstrates how to create a Spring Boot project using Spring Initializr, configure dependencies through `pom.xml`, build application models with getters and setters, and develop controllers that handle HTTP requests for CRUD operations. The project also includes running and testing REST endpoints using Postman.

---

## 🚀 Learning Objectives

After completing this lab, you will be able to:

- Generate a project using Spring Initializr
- Set up a Spring Boot project structure
- Configure dependencies in `pom.xml`
- Create Java models with getters and setters
- Build REST controllers for CRUD operations
- Run and test a Spring Boot application
- Test API endpoints using Postman

---

## ▶️ Running the Application

Clone the repository:

```bash
git clone https://github.com/yourusername/spring-restapi-lab.git
```

Navigate into the project directory:

```bash
cd spring-restapi-lab
```

Run the application:

```bash
mvn spring-boot:run
```

---

## 📌 API Testing

Use Postman to test the CRUD endpoints:

- `GET` — Retrieve data
- `POST` — Create new records
- `PUT` — Update records
- `DELETE` — Remove records
